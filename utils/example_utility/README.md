# Example utility

> [!TIP]
> Each script should start with a description of what it does.

This script creates a minimal NetCDF file containing a few points of (fictional) air temperature data.

## Usage

> [!TIP]
> Each script should provide instructions for its use, including any requirements it has.

This script requires `bash` and [`ncgen`][ncgen-docs] to be on path.
Run it with:

```sh
./make-netcdf.sh <output-dir>
```

[ncgen-docs]: https://docs.unidata.ucar.edu/nug/current/netcdf_utilities_guide.html
